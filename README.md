# bufline.nvim

A minimal always-visible buffer list in the top-right corner.

## install

```lua
-- lazy.nvim
{ "kadam-x/bufline.nvim" }
```

## usage

Works out of the box with no configuration required.

## how it looks

- `▌ lua/bufline/init.lua` — active buffer
- `  lua/plugin/bufline.lua` — inactive buffer
- `  somefile.lua +` — unsaved changes
